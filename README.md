# ذكر وفعل (Dhikr wa Fael)

تطبيق Flutter بسيط وجميل يجمع بين:
- عدّاد تسبيح تفاعلي
- أذكار الصباح والمساء وبعد الصلاة والنوم
- قائمة مهام يومية
- الوضع الليلي/النهاري

## كيفية الاستخدام في Klencod IDE

1. فك ضغط الملف zip
2. افتح المشروع في Klencod IDE
3. تأكد من وجود الملفات:
   - pubspec.yaml
   - lib/main.dart
   - باقي ملفات lib/
4. اضغط على Build / بناء APK

## المميزات

- واجهة عربية بالكامل (RTL)
- تخزين محلي باستخدام SharedPreferences
- تصميم Material 3 جميل بألوان إسلامية (أخضر + ذهبي)
- اهتزاز خفيف عند التسبيح
- إحصائيات بسيطة
